PerFlow Call Tree Viewer

读取 `calltree.json`（必需）与 `hotspot.json`（可选），从 root/main 逐层展开查看每层调用的样本数与占比。 建议用本地静态服务器打开（例如 `python3 -m http.server`），避免浏览器的本地文件跨域限制。







也可以把 `calltree.json` / `hotspot.json` / `imbalance.json` 放在同目录下，通过静态服务器打开后，点击“渲染”前先选择文件。

调用树（可展开）

热点函数（Top 200, 可选）

进程间均衡性分析（Top 20, 可选）

点击 `calltree` 节点可生成柱状图 subpanel；也可（可选）点击左侧 `imbalance.json` 条目生成单图。 拖拽 subpanel 进行融合，右上关闭。

还没有子面板：点击 calltree 节点创建柱状图；拖拽融合；右上关闭。
