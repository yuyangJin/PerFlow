PerFlow Call Tree Viewer

读取 calltree.json（必需）；可选 node_imbalance.json 与 calltree 配合在下方生成各进程占比柱状图。 建议用本地静态服务器打开（例如 python3 -m http.server），避免跨域限制。





也可将 JSON 放在网页同目录，通过静态服务器打开后选择文件并点击「渲染」。

调用树（可展开）




节点详情

点击左侧某一帧可选中并查看详情。加载 node_imbalance.json 后，可点击所有进程数据将当前帧的柱状图飞入下方左侧「单帧」列。

进程间均衡性分析（可选）

在 calltree 侧栏点击所有进程数据，单帧柱状图加载入左侧「单帧」列；将任意柱状图拖拽至另一个柱状图上融合时，新柱状图加载入右侧「融合」列，左右列之间可互相拖拽完成融合。
